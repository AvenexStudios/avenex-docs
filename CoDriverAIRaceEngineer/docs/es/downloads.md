# Descargas

Todavía no hay una descarga pública disponible.

Las builds preliminares se distribuyen únicamente por canales de prueba
aprobados por Avenex. No instales builds desde enlaces no oficiales.

Cuando se apruebe una build pública, esta página listará el instalador, paquete
portable, versión y checksum.

## Tipos de paquete preview

Los testers aprobados pueden recibir uno de estos paquetes para Windows:

- Instalador: instala la app para uso normal de escritorio.
- Ejecutable portable: útil para una prueba rápida de Team Radio en una segunda
  PC.

Las builds preliminares sin firma pueden mostrar una advertencia de Windows
SmartScreen. Continúa solo si el archivo llegó desde un canal aprobado por
Avenex.
