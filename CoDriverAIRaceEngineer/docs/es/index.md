# CoDriver AI Race Engineer

CoDriver AI Race Engineer es una aplicación de escritorio para Windows orientada
al sim racing. La versión preliminar se enfoca en radio privada de equipo,
telemetría de Assetto Corsa y un ingeniero de carrera por voz offline.

## Disponible

- [Team Radio](team-radio.md): voz privada push-to-talk entre pilotos.
- [Race Engineer](race-engineer.md): preguntas por voz en inglés respondidas con
  telemetría en vivo.
- [Instalación](installation.md): configuración básica para pruebas de preview.

## Estado preliminar

Esta documentación describe una build preliminar. Las descargas públicas, firma,
auto-update, llamadas de spotter y soporte amplio de simuladores todavía no son
funciones de producción.

Consulta las [versiones actuales](versions.md) para ver el estado de la
aplicación y sus módulos.
