# Spotter

Spotter calls are planned for a later preview.

The intended behavior is to provide concise proximity calls such as left, right,
clear, and three-wide when supported telemetry is available. The feature is not
part of the current public preview.

This page will be expanded after spotter behavior is implemented and approved.

## Current guidance

Do not rely on CoDriver for proximity calls in the current preview. Use the
simulator, mirrors, or another approved spotter tool until this feature is
released.
