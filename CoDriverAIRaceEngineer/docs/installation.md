# Installation

CoDriver AI Race Engineer currently targets Windows.

## Preview setup

1. Get the approved preview build from Avenex.
2. Close older CoDriver preview builds.
3. Run the installer or portable executable.
4. Allow microphone access when Windows asks for it.
5. Open the app and confirm the audio input, output, and model readiness panels
   show ready states before testing voice features.

## Audio setup

- Select the microphone you want to use.
- Select the output device where Team Radio and Race Engineer answers should
  play.
- Bind a push-to-talk key or supported controller input.
- Use the input signal meter to confirm the app receives microphone audio.

## Telemetry setup

Assetto Corsa telemetry is detected locally while a driving session is running.
Start a session before asking telemetry questions such as position, fuel, speed,
gear, RPM, lap time, or session time.

## First run

The first run may prepare local voice resources before the race engineer is
usable. Keep the app open until the readiness panel reports ready.

If the app cannot access the microphone, check Windows privacy settings and the
selected input device.
