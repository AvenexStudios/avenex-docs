# CoDriver AI Race Engineer

CoDriver AI Race Engineer is a Windows desktop companion for sim racing. The
preview focuses on private team radio, Assetto Corsa telemetry, and an offline
voice race engineer.

## What is available

- [Team Radio](team-radio.md): private push-to-talk voice between drivers.
- [Race Engineer](race-engineer.md): English voice questions answered from live
  telemetry.
- [Installation](installation.md): basic Windows setup for preview testing.

## Preview status

This documentation describes a preview build. Public downloads, signing,
auto-update, spotter calls, and broader simulator support are not production
features yet.

See [current versions](versions.md) for the application and module status.
