# Troubleshooting

## Microphone is not detected

- Confirm Windows microphone permissions are enabled.
- Select the intended input device in the app.
- Speak while watching the input signal meter.
- Close other software that may hold exclusive access to the microphone.

## Team Radio cannot connect

- Confirm every driver is using the same approved build.
- Recreate the team invite code.
- Check that the network allows WebRTC traffic.

## Race Engineer does not answer

- Wait until the readiness panel reports ready.
- Ask a short supported question in English.
- Confirm Assetto Corsa telemetry is available if the question needs live data.
- Hold the ask input while speaking, then release it to send the question.
- Try a written question to confirm the engineer pipeline is otherwise working.

## Voice sounds degraded

The app may use a fallback voice if local voice playback is unavailable. Restart
the app and confirm the readiness panel reports the local voice as ready.

## Telemetry values are missing

- Start Assetto Corsa before asking telemetry questions.
- Enter a live driving session, not only the launcher or menu.
- Confirm the CoDriver telemetry panel shows speed, gear, RPM, fuel, and session
  data.
- If a specific field is unavailable, the engineer should answer that it does
  not have that data.
