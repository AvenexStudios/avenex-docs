# Overlays

Avenex Race Control uses overlay families for different race-control situations.

## Families

- **Family A**: persistent live monitors, counters and post-race time indicators.
- **Family B**: race-control announcements and sanctions.
- **Family C**: advisory cards with countdowns or short driver instructions.
- **Family D**: native Assetto Corsa HUD only for disqualification or native-only
  states when enabled.
