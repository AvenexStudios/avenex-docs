# Instalación

## Antes de empezar
Necesitas Assetto Corsa, Custom Shaders Patch (CSP) y el paquete cliente de
Avenex proporcionado por tu liga o administrador. Usa las versiones de cliente
y servidor entregadas juntas. Consulta al proveedor la versión de CSP
compatible; no se garantiza compatibilidad con todas sus versiones.

## Instalación para pilotos
1. Cierra el juego y respalda la configuración de Avenex existente.
2. Extrae el paquete cliente en la instalación de Assetto Corsa conservando
   las carpetas. El directorio de la app es `apps/lua/AvenexIncidents`.
3. Activa la app en la configuración de aplicaciones Lua de CSP y entra al servidor.
4. Comprueba los contadores y avisos esperados. Si alguno está oculto,
   consulta si el servidor lo desactivó.
5. Vuelve a entrar a la sesión después de actualizar archivos del cliente.

La carpeta puede conservar el nombre AvenexIncidents aunque el producto se
llame Avenex Race Control. No renombres las carpetas del paquete manualmente.

## Instalación del servidor
Usa el paquete de AssettoServer compatible con el plugin entregado, no el
ejecutable original de servidor dedicado de Assetto Corsa sin modificar.
Mantén compatibles las versiones del cliente, plugin y servidor.

Instala el plugin respetando la estructura suministrada. Configura el token
del admin de forma privada y abre `/avenex/admin` en la dirección HTTP del
servidor. Consulta [Administración](server-admin.md) para elegir las reglas.
No compartas el token administrativo con pilotos ni en invitaciones públicas.

## Actualizaciones
Respalda configuración y resultados antes de reemplazar un paquete. Sustituye
solo los archivos indicados en sus instrucciones. Cambiar un ajuste no borra
sanciones ni resultados anteriores. Consulta las [versiones](versions.md) y
vuelve a conectar los clientes después de actualizar.
