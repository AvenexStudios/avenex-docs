# Versiones

La versión actual de **Avenex Race Control es 0.1.0**.

Esta edición es preliminar. Las versiones anteriores a 1.0.0 no representan
un release de producción. Usa los paquetes compatibles suministrados por tu
administrador; los números de módulo no son instaladores independientes.

## Módulos incluidos

| Módulo | Versión |
| --- | --- |
| Detección y puntuación de incidentes | 0.1.0 |
| Cortes de pista | 0.1.0 |
| Drive-through | 0.1.0 |
| Stop & Go | 0.1.0 |
| Descalificación | 0.1.0 |
| Penalización de tiempo | 0.1.0 |

Los demás controles disponibles se distribuyen con la versión de la aplicación,
sin una versión de módulo independiente indicada aquí. Consulta [Administración](server-admin.md)
para conocer disponibilidad y opciones.
