# Overlay Gallery

This page tracks the screenshots that should be captured for each public overlay
state. Captures are published only after in-game validation, so every image shown
here should represent a real Assetto Corsa session.

## Capture Rules

- Use an in-race cockpit or chase-camera screenshot where the overlay is readable.
- Keep the game HUD state representative of production use.
- Avoid debug windows unless the screenshot is explicitly for troubleshooting.
- Use the exact file names listed below under `assets/overlays/`.
