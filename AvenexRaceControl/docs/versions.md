# Versions

The current **Avenex Race Control version is 0.1.0**.

This is a preview edition. Versions below 1.0.0 do not represent a production
release. Use compatible packages supplied by your administrator; module
version numbers are not independent installers.

## Included modules

| Module | Version |
| --- | --- |
| Incident detection and scoring | 0.1.0 |
| Track cuts | 0.1.0 |
| Drive-through | 0.1.0 |
| Stop & Go | 0.1.0 |
| Disqualification | 0.1.0 |
| Time penalty | 0.1.0 |

Other available controls ship with the application version and do not have an
independent module version listed here. See [Administration](server-admin.md)
for availability and settings.
